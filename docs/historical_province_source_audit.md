# 历史注册省份来源审计

## 审计范围

目标总体为5,272家沪深非金融企业、28,548个合法firm-year，覆盖2020—2025年。当前企业Profile中的省份仅作为静态比对值，不进入历史主变量。

## 来源结论

- 主来源：巨潮资讯官方披露检索与上市公司正式年度报告，Tier H1。
- 年报以公司代码和报告年度检索，保存公告编号、报告年度、披露日期和公开文档地址。
- 年报PDF经公开地址直接读取，优先提取内嵌文本层；不以OCR代替文本层。
- 带有效日期的注册地址迁移记录作为Tier H2证据，用于处理年报披露日晚于对应年末的时间错位。
- EastMoney静态Profile只保留为`static_fallback_only`和一致性审计，不能覆盖历史主变量。

审计样本包含上交所、深交所当前企业、退市企业、近期IPO与长期上市公司。五个跨省或迁址案例均在官方报告/公告中核实旧址、新址与生效日期：300370、000668、002388、600715、002453。五例均通过；其中至少一例证实报告期后发生迁址时，报告首页/公司概况地址不能直接代表前一报告年度年末。

## 来源边界与限制

年报年度字段与年末历史状态并非在所有文件中天然等价。对可观察到有效日期的迁址，按12月31日边界重建并标记`historical_inferred`；无可用有效日期时，不用静态Profile补成历史值。解析不到省级行政区的地址维持静态fallback或missing。退市企业与部分近期IPO的历史覆盖低于当前企业层，正式结果须分层报告，不因缺失删样本。

## 全量覆盖收口（2026-09-26）

早期全量结果中的 86.07%/87.63% 为修复前历史快照，不再代表当前 Gate。针对实际返回公告审计发现，旧标题匹配器漏掉 1,172 条正式年度报告候选（1,122 家受影响企业的重查范围，涉及 750 个证券代码），主要为更新/修订/更正后缀以及缺少额外“年”的标题；新匹配器纳入这些正式报告并继续排除摘要。对注册地址解析失败样本稳定抽取 100 份 PDF，73 份上下文出现旧解析器未识别的地址标签/相邻行格式；扩展字段标签和跨行提取，并以回归测试保护办公室地址不误识别。地址映射另修正显式城市名与单字省份别名的优先级。

重查只刷新 1,122 家、1,758 个 firm-year 所需报告，既有合法缓存复用。最终 5,272 家、28,548 个 firm-year、53/53 chunks：confirmed 23,944、inferred 2,462、static fallback 2,110、missing 32、conflicts 4。SSE current 92.44%，SZSE current 94.05%，Full Gate `HISTORICAL_PROVINCE_RESEARCH_GATE_PASS`；精确键匹配、重复/非法键及静态主变量违规检查均通过。当前 Stata sentinel 为 `HISTORICAL_PROVINCE_VALIDATION_PASS`。逐行诊断见[全量覆盖诊断](historical_province_coverage_diagnosis.md)。

退市代码仍不通过猜测 orgId 或证券代码转换补齐；无法证实的迁址日期冲突继续保留。当前 Gate PASS 不代表每个子组均达到 90%：SZSE 近期 IPO 子组为 89.68%，退市子组约 66%—68%，均按预先定义的范围单独报告。未抓取新政策文本、未运行政策匹配、BSE、专利或回归。

本轮对 CNINFO 当前证券目录（6,258 个代码）作一次只读核验：current SSE/SZSE 5,042 家均可找到；退市 SSE 91/95、SZSE 126/135 可找到。目录缺失的 13 家退市企业没有被转换或猜测 orgId；目录是否解释某条具体未覆盖记录需逐公司证据，未作总体推断。

本报告不包含企业级真实数据、年报全文、缓存或运行日志。
