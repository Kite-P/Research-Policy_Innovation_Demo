## 一、当前阶段目标

当前阶段主要进行实证研究所需的数据工程基础训练，重点建立可复现的 Python 科研环境，并完成公司年度面板训练数据的生成与初步质量审计。

### 2. 模拟科研数据生成器

已编写可复现的数据生成脚本：

`src/generate_training_data.py`

生成三类训练数据：

- 公司年度财务面板数据
- 公司基本信息数据
- 公司年度专利数据

数据生成采用固定随机种子，可以重复生成一致的训练数据。

为模拟真实科研数据环境，数据中主动加入了缺失值、格式不一致、重复记录、主键冲突和异常值等问题。

### 4. 原始财务数据审计

已建立：

`notebooks/01_data_audit.ipynb`

对 `firm_financials.xlsx` 进行了第一阶段质量审计。

数据规模：

- 260 条原始记录
- 11 个变量
- 理论观测单位为公司 × 年份（firm-year）
- 潜在主键为 `stock_code + year`

当前已识别：

- pandas 原生缺失值：4 个
- `"-"` 形式伪缺失值：2 个
- `"2023年"` 年份格式异常：6 条
- 千位逗号数值格式：2 条
- ROE 百分号格式：2 条
- 完全重复的后续记录：10 条
- 位于重复 firm-year 主键组中的记录：40 条
- `stock_code` 缺失记录：1 条

在对已知格式问题进行审计性标准化后，暂未发现其他无法解释为数值的未知文本。

同时发现部分重复 firm-year 并非简单的完全重复，而是存在同一公司、同一年但财务指标取值不同的冲突记录，因此后续不能直接使用 `drop_duplicates()` 进行机械删除。

## 三、当前认识

本阶段重点不是立即进行回归分析，而是先建立规范的数据审计流程。

目前已经能够区分：

- 真正缺失值
- 伪缺失值
- 格式异常
- 完全重复记录
- firm-year 主键冲突

并坚持先审计、后制定清洗规则，避免在不了解数据问题来源的情况下直接删除或转换原始数据。
