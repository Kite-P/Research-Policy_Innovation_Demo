# 导师科研项目

## 项目目的

用于财务会计、公司金融和企业创新方向的科研训练。

当前训练重点包括：

- Python 数据清洗
- 上市公司面板数据构建
- 财务数据库匹配
- 政策文本处理
- 专利数据处理
- Stata 实证分析
- 可复现科研工作流

## Python 环境

项目 Python：

Python 3.13.15

虚拟环境：

.venv

环境由 uv 管理。

## 项目结构

- data/raw：原始数据
- data/processed：处理后的数据
- data/external：外部辅助数据
- notebooks：探索性分析与训练 Notebook
- src：可复用 Python 代码
- tests：测试代码
- docs：研究文档
- results：分析结果、图表和回归结果

## 原则

原始数据、处理数据和研究结果默认不提交到 Git 仓库。
